# dsh-asset-archiver 1.3.4

## 用途

把本地 DeepSeek Harness 的会话按「工作区」归档到阿里云 OSS，并可选择性地归档工作区文件；在其他设备上选择云端工作区、指定本地目录后，会话与文件一起恢复。

## 使用步骤

1. 安装并启用插件，侧栏底部出现插件入口。
2. 点击入口打开浮层窗口（遮罩 + 居中面板），不占用 DSH 原有会话界面。
   - 关闭：右上角「关闭」、点击遮罩或按 Esc。
3. 首次打开进入「设置」填写 OSS 配置：
   - `endpoint`（例如 `oss-cn-hangzhou.aliyuncs.com`）
   - `region`（例如 `oss-cn-hangzhou`）
   - `access-key-id` / `access-key-secret`
   - `bucket-name`
   - 可选 `prefix`（默认 `dsh-asset-archiver`）
4. 点「测试连接」确认可用后保存。
5. 「上传」页：
   - 勾选工作区 = 只上传该工作区的会话；
   - 点击工作区名称展开文件树，文件夹可继续展开/收起；
   - 勾选文件夹 = 选中其下全部可上传文件（保持树形结构）；也可展开后逐个勾选文件；
   - 文件树顶部提供整个工作区的「全选 / 清空」；
   - 「上传全部工作区」上传所有会话与已勾选的文件。
6. 「拉取」页刷新云端工作区 → 选中工作区 → 选择本地目录 → 「拉取该工作区」：
   - 工作区名右侧的「同步工作区文件」开关默认关闭，关闭时只拉取会话；
   - 打开开关后，会话与已归档文件一起写入；切换到其他工作区时开关恢复关闭；
   - 会话保留原 agent preset，首次打开时由 DSH 挂载对应工具；1.3.2 及更早版本已拉取的会话需删除后重拉。

## 文件归档规则

- 云端路径：`<prefix>/v1/workspaces/<workspaceKey>/files/<encoded path>`；
- 清单中的 `files` 记录 `path/bytes/sha256/contentType/uploadedAt`；
- 只处理普通文件，跳过符号链接、`node_modules`、`.git`/`.hg`/`.svn`；
- 文件以工作区相对路径保留树形结构；空目录不保留；
- 单文件 ≤ 100 MB，单次列表 ≤ 2000 个；
- 上传/下载拒绝绝对路径与 `..`，下载校验 SHA-256；
- 本地已存在的同路径文件跳过，不覆盖；
- 拉取页文件同步开关默认关闭；关闭时不访问文件对象，仅拉取会话；
- 仅勾选工作区不会上传任何文件；上传会话时会保留云端已有的文件索引。

## 限制

- 会话仍为工作区级上传/下载，暂无会话级勾选；
- 文件不支持删除/重命名同步与覆盖策略；
- 不迁移会话附件/图片对象；
- 任务同步执行，无任务队列/进度/取消；
- 仅中文界面；
- 配置为明文保存，仅建议私用环境。

## 卸载

在插件管理中禁用或移除 `dsh-asset-archiver`。`DSH_HOME/dsh-asset-archiver/` 下的配置不会被删除。
